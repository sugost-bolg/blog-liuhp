## 架构概览

```
┌────────────────────────────────────────────────────────────────────┐
```

## 流量走向

### 透明模式 (无感代理)
1. 客户端发起 TCP 请求 (如 curl www.google.com)
2. 服务器 iptables 捕获流量 → 重定向到 redsocks:12345
3. redsocks 转发给 ss-local:1081 (SOCKS5)
4. ss-local 加密后发给 gost:10086
5. gost 走 relay+tls 协议发送到出口节点
6. 出口节点 8.217.83.160:10086 转发到目标网站

### 手动模式
1. 客户端配置 SOCKS5 代理 8.156.79.94:1081
2. 直接走 ss-local → gost → 出口

## 关键配置

### gost 配置
```json
{
  "ServeNodes": ["tcp://:10086"],
  "ChainNodes": ["relay+tls://8.217.83.160:10086"]
}
```

### ss-local 配置
```bash
ss-local -s 127.0.0.1 -p 10086 -l 1081 -k 密码 -m aes-256-gcm
```

### redsocks 配置
```conf
redsocks {
    local_ip = "0.0.0.0";
    local_port = 12345;
    ip = "127.0.0.1";
    port = 1081;
    type = "socks5";
}
```

### iptables 规则
```bash
# 排除本地端口
iptables -t nat -A OUTPUT -p tcp --dport 22 -j RETURN
iptables -t nat -A OUTPUT -p tcp --dport 1081 -j RETURN
iptables -t nat -A OUTPUT -p tcp --dport 10086 -j RETURN
iptables -t nat -A OUTPUT -p tcp --dport 12345 -j RETURN

# 其他 TCP 流量走代理
iptables -t nat -A OUTPUT -p tcp -j REDIRECT --to-ports 12345
```
