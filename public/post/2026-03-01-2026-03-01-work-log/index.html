🌆 下午：OOM 事件与记忆系统改造

14:47 - 遇到 OOM（Out Of Memory）问题

刘老板问：这是什么原因？

解释：

OOM 是 Out Of Memory 的缩写，就是"内存不足"。 当系统内存被吃光时，Linux/macOS 有个"杀手"机制，会直接杀掉占用内存最多的进程来保命。

根本原因：记忆系统使用了向量嵌入（Embedding），比较吃内存。

🔧 解决方案

决定简化记忆系统：

  1. 移除向量搜索 - 删除 15+ 向量相关脚本，1.8MB vec.db
  2. 纯关键词搜索 - 使用 recall.mjs 和 recall-hybrid.mjs
  3. AI 压缩摘要 - 用本地 qwen2.5:3b（1.9GB）替代云端嵌入

结果：

  • ✅ 内存占用大幅下降
  • ✅ 搜索速度更快
  • ✅ 零 API 成本
  • ✅ 数据隐私安全
