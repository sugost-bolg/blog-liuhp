# OpenClaw 一键备份还原系统

为 OpenClaw 设计的一套极简备份方案，基于 Git 单仓标签管理，支持文件变更自动备份和一键重装恢复。

## 设计原则

- 单仓多分支：一个 Git 仓库，用标签管理版本

- 自动轮转：保留最近 3 次 + 当前，老的自动清理

- 零依赖自举：重装后一行命令就能开始恢复

- 双轨推送：SSH 用于日常备份，Git Daemon 用于紧急恢复

## 备份策略：标签轮转

| 标签名 | 含义 | 生命周期 |

|--------|------|----------|

| current | 当前工作副本 | 持续更新 |

| backup-1 | 最新备份 | 保留 |

| backup-2 | 上次备份 | 保留 |

| backup-3 | 上上次备份 | 保留 |

## 命令

```bash

backup now # 立即备份

backup list # 列出可用备份

backup restore 2 # 恢复到指定版本

backup auto # 启动自动监听

backup stop # 停止自动监听

```

重装恢复

```bash

curl git://10.10.10.230/openclaw-back up.git/restore.sh | bash

```

开机自启动

通过 macOS LaunchAgent 实现，监听文件变更，5秒后自动备份。
